# أرشيف بطاقات الزبائن — نسخة أولية

هذا مشروع Android أولي بواجهتين: تصوير الوجه الأول وتصوير الوجه الثاني. بعد التصوير يحاول قراءة النص العربي عبر Tesseract ثم يحفظ الصورة تلقائياً في مجلد التطبيق `Pictures/بطاقات الزبائن` باسم النص المستخرج مع توقيت لمنع استبدال الملفات.

## ملاحظات مهمة قبل الاستخدام الحقيقي
- هذه نسخة أولية تحتاج اختباراً على صور بطاقات فعلية؛ استخراج الاسم من OCR ليس مضموناً، وقد يختار سطراً غير الاسم.
- ملف اللغة العربية `ara.traineddata` يُنزّل عند أول استخدام، لذلك يلزم الإنترنت أول مرة. بعد تنزيله يعمل التعرف محلياً.
- حالياً لا يوجد اختيار يدوي للاسم أو قصّ تلقائي لمنطقة الاسم؛ أضفنا الاسم غير المقروء كـ `اسم_غير_واضح` بدلاً من إيقاف الحفظ.
- الحفظ في مجلد عام ظاهر: Pictures/بطاقات الزبائن، ويمكن الوصول إليه من تطبيق الملفات ومعرض الصور.
- مشروع المصدر ليس APK جاهزاً. يتيح GitHub Actions بناء APK تجريبي بعد رفع المشروع إلى مستودع GitHub وتشغيل workflow.

## بناء APK
ارفع ملفات هذا المشروع إلى مستودع GitHub، ثم افتح Actions وشغّل `Build Android APK`. نزّل artifact باسم `customer-cards-archive-apk`.
